# Masked report (copy this; fill in only what it asks for)

Use for anything that goes from the CUI side to a public repository's issue, pull request, comment or chat. If a field cannot be filled without a name, a part number or a program word, leave it blank and say "withheld".

- Public repository and version (tag and commit):
- What was done (generic verbs: loaded a model, attached a BOM, opened a drawing set, ran the check):
- Result: pass / fail
- Counts (parts loaded, rows matched, quantity mismatches, failed requests): numbers only
- File **hashes** (SHA-256) of anything the public side might need to recognise: hashes only
- Field names or message **types** involved (for example "load-bom, refDes"): names of fields, never values
- Generic error text (the message with every name, number, URL and path removed):
- Not attached, on purpose: screenshots, console output, files, logs, part numbers, program or host names, user ids, e-mail addresses, controlled URLs

Reviewed by a person before posting: yes / no
